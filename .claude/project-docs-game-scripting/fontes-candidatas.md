# Fontes candidatas

Fila de espera de fóruns/boards citados dentro de anúncios mas **ainda não
catalogados** em `fontes.md`. Quem decide se entra é o Pedro.

O arquivo nasceu vazio em 12/set/2026 — nunca veio no pacote de migração.
**Não preencher com suposição:** só entra fonte encontrada numa rodada real.

## Como uma fonte chega aqui

Da seção "Expandir fontes automaticamente" do `SKILL.md`:

1. Testou `URL/categories.json` e respondeu? É Discourse → **não vem pra cá**,
   vai direto pra `fontes.md` e pro `coletor.py`.
2. Não respondeu? **Registra aqui** pro Pedro avaliar.
3. Exige login ou token? **Não adicionar** — procurar agregador legal que já
   cubra essa fonte (foi assim que se chegou ao RoHire).

## Formato

```markdown
## nome-da-fonte

- **URL:** https://...
- **Onde apareceu:** link do anúncio que citou
- **Data:** AAAA-MM-DD
- **Discourse?** não / não testado / sim (se sim, não devia estar aqui)
- **Exige login?** sim / não / desconhecido
- **Primeira impressão:** volume, idioma, se paga em dinheiro real
- **Veredito do Pedro:** pendente / adotar / descartar (+ motivo)
```
