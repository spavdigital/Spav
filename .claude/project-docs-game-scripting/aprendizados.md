# Aprendizados

Histórico de correções. A skill escreve aqui ao fim de **cada** rodada — ver a
seção "Aprender a cada rodada" no `SKILL.md`.

O arquivo nasceu vazio em 12/set/2026: o original nunca veio no pacote de
migração e o conteúdo anterior, se existiu, se perdeu. **Não preencher com
suposição** — só entra o que foi observado numa rodada real.

## Formato

Uma entrada por descoberta, mais recente no topo:

```markdown
## AAAA-MM-DD — título curto do que mudou

- **Acreditava-se:** o que estava escrito nos arquivos antes
- **Descobriu-se:** o que a rodada mostrou
- **Fonte:** link do anúncio/tópico, ou nome do arquivo contradito
- **Ação:** que arquivo foi corrigido (ou "nenhuma — só registro")
```

O que merece entrada: regra de fórum desconhecida, fonte nova citada dentro de
um anúncio, faixa de preço diferente da registrada, padrão no que o Pedro
aprova ou rejeita, rascunho que gerou resposta (e o que ele tinha de diferente).
